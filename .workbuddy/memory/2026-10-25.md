## 实测发现（写进测试注释，都是既有设计不是 bug）
- WAL 条目**不会**在磁盘写成功后即时删除：stream:wal:0 长期挂 24 条，
  清理靠 RedisMaintenanceTask 每天 3:20 轮换 → 归档删除必须等轮换，
  且重启会按 WAL 重建已删文件（归档被撤销，但服务端能正常启动）
- order_write.lua:107 HSET stock cjson.encode(tostring(newStock))：
  Redis hash 里 stock 值是**带引号**的 JSON 字符串（与 Java Jackson 对齐的约定）
- 服务端比文档强：删员工即刻踢线（authenticatedPerms 账户存在性 → 401，
  旧 README 的 403 过时）；删不存在商品 → 404
